# Student Marksheet Analysis (R)

A simple R program to calculate the **minimum, maximum, and average marks** of students based on Gender (Male and Female).

## Requirements
- R Programming Language
- readxl package

## Files
- `Student_Marksheet.R` – R program
- `Student_Marksheet.xlsx` – Input dataset

## How to Run
1. Keep both files in the same folder.
2. Open the R script in RStudio.
3. Run the program.

## Output
The program displays:
- Minimum marks by Gender
- Maximum marks by Gender
- Average marks by Gender

**Note:** The Excel file must be named `Student_Marksheet.xlsx`.
